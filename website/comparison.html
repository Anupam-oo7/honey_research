How many guesses before the real password?

Share of all trials (including users whose password is outside the dictionary and can never be found) where the genuine password appears within the given number of candidates. For Honey Encryption, plausible decoys may also pass the checks.

A candidate is a password guess whose output passes the attacker's checks. An authenticated PBE result can be verified; a Honey Encryption candidate still needs outside verification because it may be a believable decoy.

When the password is not in the dictionary, what does the attacker see?

Authenticated PBE rejects every guess, so the attacker learns the dictionary failed. Honey Encryption keeps returning plausible results, so a miss is not visible.
