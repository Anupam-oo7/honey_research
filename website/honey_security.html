Level 3 · Can a classifier tell the difference?

A machine-learning classifier is trained on one set of synthetic examples and tested on held-out examples it has not seen before.

Held-out classifier test
Classifier AUC--0.5 is chance; higher scores mean easier separation

Classifier separation

Higher curves mean more genuine examples can be found at the same false-alarm rate.

Patterns the classifier used

Change in AUC when each feature is shuffled; larger drops indicate more useful signals.

This is a statistical test on synthetic data, not proof that an attacker can identify every individual output. AUC near 0.5 is close to chance; performance can change with the data, model, or features.

All samples, names, card numbers, and passwords on this page are synthetic. Statistical similarity summarizes these generated examples; it is not a claim about real people or real-world security.
